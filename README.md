# MealMate Australia prototype

## Run it
Open `index.html` in a modern browser on a computer or phone. It works without a server and stores saved plans locally in the same browser.

## Included
- 7- and 14-day planning
- 1–8 people
- Dinner-only, lunch-and-dinner, or all-meal modes
- Dietary/food preference filters and foods-to-avoid field
- Recipe library with instructions and estimated nutrition
- Consolidated shopping list with package estimates
- Illustrative ingredient costs, budget indicator, tick-off list
- Swap meal, print, copy list, save/load plans in browser local storage

## Important limitations
- Prices are illustrative estimates, not live supermarket prices.
- No official retailer feeds or store-specific pricing APIs are connected.
- Nutrition figures and ingredient costs are approximate. Event quantities and costs are rough planning estimates, not catering advice or live prices.
- Prototype does not have user accounts, cloud sync, payments, or app-store packaging.
- Dietary filters are preference filters, not medical advice; allergies must be checked against product packaging.
